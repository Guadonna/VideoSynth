Для воспроизведения расчётов нужен Python 3 без дополнительных зависимостей:

```sh
python3 docs/research-v0.4/calculations.py
```

Расчёты и модель связности не заменяют испытаний аппаратного прототипа.
Статусы подтверждения, ограничения доступа к документации и каталогу JLCPCB,
технические риски и план испытаний приведены в отчёте.

Текущий этап — исследование. Электрическая схема и PCB не разработаны;
переход к ним требует отдельного согласования.
