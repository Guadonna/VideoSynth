# VideoSynth

Исследование цифрового видеосинтезатора. Текущая редакция **v0.5**: один выход 480i, экранная матрица до 36 связей, два CV DC…100 Гц, питание Eurorack.

- [Текущие требования v0.5](docs/requirements/video_synth_TZ_v0.5.md)
- [Краткая выжимка v0.5](docs/summary-v0.5.md)
- [Подробное исследование v0.5](docs/feasibility-v0.5.md)
- [PDF v0.5](docs/feasibility-v0.5.pdf)
- [Архив материалов v0.5 с историей исследования](docs/VideoSynth-feasibility-v0.5.zip)
- [Предварительные компоненты и смета](docs/research-v0.5/components-preliminary.csv)
- [Расчёты, источники и новый снимок каталога](docs/research-v0.5/)

Для воспроизведения расчётов нужен Python 3 без дополнительных зависимостей:

```sh
python3 docs/research-v0.5/calculations.py
```

Первый кандидат — один ESP32-P4; P4+RP2350A остаётся резервом для видеотайминга. Выполнение максимального режима на конкретном MCU должно быть подтверждено прототипом. Расчёты не заменяют физических измерений, снимки каталога не являются резервом компонентов или котировкой PCBA.
