ERC не доказывает правильность выбранного корпуса или datasheet pinout: часть выводов пассивна, а power flags являются явными допущениями о внешних источниках. Поэтому добавлена независимая сверка всех площадок и отдельные проверки Eurorack, module power и межплатного шлейфа. Эта сверка тоже не заменяет физическое ревью модуля и компонентов.

Автотесты проверяют максимальные 36 связей и отказ 37-й, неизменность матрицы при выключении OSC из микса, циклы и самомодуляцию, X/Y-зависимость, чётные/нечётные строки, чёрный кадр с синхронизацией, защиту загрузки пресета, 900900 отсчётов и полупериоды 480i. Браузерный тест проверяет standalone с блокированием всех запросов после HTML; внешних ресурсов не требуется. Сам браузер хоста запрещает прямую навигацию `file://`, поэтому этот путь не объявлен непосредственно испытанным здесь.

## Численные результаты

SPICE: максимальное расхождение DC с номинальной формулой **3,05 мкВ** (это точность идеальной модели, не точность реального устройства); на ±10 В получены **2,72206 / 0,42980 В** у АЦП; на 100 Гц **−0,8462 дБ относительно DC**. Нет моделей перегрузки ОУ, диодов, TMUX power-off, ESD, импульсного buck и паразитик видеотракта.

Нативный C-бенчмарк на данном x86_64 хосте, GCC 14.2, `-O3`, один сценарий с 36 циклическими связями: **41,78 мс/кадр в среднем за 20 кадров** при отдельном повторе после тестов. Это медленнее бюджета 33,37 мс даже на этом хосте. Сценарий не является полным worst-case по morph/UI/CV; число в JSON может меняться при повторе из-за нагрузки хоста. **Утверждать, что этот эталонный алгоритм уже работает в real-time на P4, оснований нет.** Нужны оптимизация и аппаратное измерение; возможен пересмотр архитектуры.

Расчёт загрузки: 10,358 млн пикселей/с; 62,146 млн вычислений OSC/с; до 372,875 млн накоплений модуляции/с. Это объясняет, почему прошивка является самостоятельным следующим этапом, а не автоматической компиляцией эмулятора.

## Как повторить

Приложение использует включённый WASM; для запуска нужен только Node.js 20+ или автономный HTML. Для полного цикла нужны KiCad 9 с pcbnew, C-компилятор, Chromium, libngspice, Python 3, Node.js и wasi-sdk 25.

```sh
bash scripts/setup-cloud.sh
npm test
bash scripts/verify-hardware.sh
python3 scripts/draw_panel.py
```

В отдельном терминале запустить `npm start`, затем:

```sh
npm run test:browser
python3 scripts/verification_asset.py
node scripts/bundle.mjs
```

`setup-cloud.sh` проверяет зависимости базового образа и устанавливает npm/wasi-sdk без root. Он не устанавливает системный KiCad/Chromium/libngspice на произвольной ОС: они уже присутствуют в выбранном облачном образе. Для другого Linux установите их пакетным менеджером своей системы. `CHROMIUM` и `WASI_CC` позволяют задать пути. В облаке HOME доступен только для чтения; KiCad использует XDG-каталоги внутри `/workspace`.

Готовые PCB открываются без генератора и autorouter. **Не запускать `build_kicad.py` без `--schematics-only` на рабочей разводке:** это намеренно создаёт исходные платы заново и удаляет трассировку. Изменение single-source design.py также требует последующего согласованного изменения PCB, повторного ERC/DRC и сверки; скрипт не выполняет магический ECO.

## Что было заблокировано и как решено

- Системная установка пакетов без root недоступна. Использованы уже установленные KiCad/Chromium, shared libngspice и локальный wasi-sdk; текущие проверки выполнены, ожидания разрешения на установку нет.
- Запись настроек KiCad в read-only HOME заменена штатными XDG-путями в `/workspace`.
- Прямая `file://`-навигация Chromium запрещена политикой браузера. Проверка автономного HTML выполнена с полной блокировкой вторичных сетевых запросов.
- Datasheet Bourns дросселя возвращал HTTP 403. Isat/дерейтинг остаются незакрытым пунктом BOM, не подменены предположением.
- Заводская комплектация всех конкретных SMD, коммерческая PCBA-котировка и DFM ещё не получены; производство не заказывалось.
- Настройка среды сохраняется отдельным черновиком. Сохранение черновика само по себе не публикует образ и не подтверждает восстановление новой машины.

Ни один провал CAD-проверки не скрыт исключением: локальные airwires/зазоры исправлены, окончательные отчёты чистые.
