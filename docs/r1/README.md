# VideoSynth R1 — схема, PCB и лаборатория эмуляции

23 октября 2026. Пользователь разрешил разработку схемы и PCB после исследовательской v0.5 и подтвердил готовый модуль ESP32-P4 и панель 42 HP. Старый запрет проектирования в документах v0.4/v0.5 относится к завершённому этапу. Разрешения на производство нет; заказы не создавались.

Созданы **две электрические схемы и две полностью соединённые четырёхслойные PCB KiCad 9**: основная плата и плата органов управления. В R1 используется Olimex ESP32-P4-DevKit Rev.D1. Это проверяемый инженерный прототип, ещё не выпуск для изготовления.

Краткий вывод: логика шести осцилляторов, экранной матрицы и одного микса реализована и проверяется в приложении. ERC, DRC и независимая сверка соединений проходят. Линейная модель входа CV проходит SPICE-проверку. **Работоспособность собранной электроники и 720×480/29,97 при 36 связях на ESP32-P4 пока не подтверждены.** В репозитории есть переносимое ядро C и браузерный стенд; драйверов платы и законченной ESP-IDF-прошивки ещё нет.

Перед изготовлением важнее всего проверить непрерывность PARLIO/DMA, максимальный DSP-сценарий, питание модуля без USB, номиналы и поведение CV при выключении. Также нужно утвердить точные модели ручек/дисплея и конструкцию крепления двух плат. Нулевой DRC этих вопросов не решает.
